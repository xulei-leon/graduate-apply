申请人现有优势是 Python 分析与统计推断；没有经核实的 ChaNGa / GASOLINE、SPH、C++ 并行开发或宇宙学模拟运行经历。信中主张从模拟结果分析与观测比较入手，并希望补足 hydrodynamics 与 galaxy formation 基础，不把分析背景写成成熟模拟开发经验。
