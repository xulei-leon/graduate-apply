# Physics Masters — Fall 2027 逐校 Offer 概率评估

评估日期：2026-10-05。招生依据核查及访问尝试日期：2026-10-05。

本报告独立整理本次对话中的评估，不更新申请总览、学校档案或索引。评估覆盖当前总览的39所学校记录；Sorbonne与Paris Cité联办Paris Physics Master，不能计为两次独立机会。ANU已获普通版offer，按已发生的录取事实记录。

## 1. 总体判断

这轮申请有拿到更多offer的现实机会，但CGPA 3.0仍会明显限制成绩筛选严格的项目。相对值得争取的是KIT、Heidelberg、UZH、Geneva、Bern，以及Stony Brook、NYU、Tufts等独立硕士项目。加拿大应优先核查Western和UVic；ETH、EPFL、PSL属于低概率冲刺。

上述排序同时受资格、课程等效、研究名额和资金安排影响，不是按学校排名推算。科研背景能使申请更具体，但不能绕过明确的入学门槛。

## 2. 概率含义与申请人假设

**下文百分比是主观申请规划区间，不是学校公布的个人录取率，不是经过历史录取数据训练的预测模型，也不是统计置信区间。** 它们用于比较申请投入的优先级；相差5个百分点不能视为有可靠的统计差异。官方来源支持招生事实，不直接支持本报告的个人概率数字。

本次评估采用以下口径：

| 变量 | 本次使用的假设及证据边界 |
|---|---|
| 学历 | University of Toronto，Honours Bachelor of Science，Physics Specialist；预计2027年6月毕业。 |
| 成绩 | CGPA 3.0/4.0；最近两年、三四年级及核心物理数学课成绩未知，不由CGPA直接换算各校百分制或德国成绩。 |
| GRE | General GRE 317，Q166；不等同于Physics Subject GRE。多数项目不要求或不接受GRE，不能假定其足以抵消GPA。 |
| 科研1 | MaNGA暗物质晕c–M关系的Bayesian/PyMC分析，有手稿及公开作品；不按已发表论文计算。 |
| 科研2 | 模拟H → ZZ* → 2e2μ的MLP、pyhf profile likelihood、Shapley attribution、MC bootstrap及覆盖率诊断；有具体代码、分析和手稿，不按已发表成果或实验合作组测量计算。 |
| 推荐信 | 用户于本次对话确认：两个科研项目的导师各提供一封推荐信。信的力度未知，不默认两封都是强推荐。 |
| 第三封推荐 | 对要求三封的项目，下表假定最终能够补齐第三封合格推荐。仅有两封且未获正式豁免时，材料不完整，表中区间不适用。 |
| 英语材料 | UofT英语授课背景可支持豁免申请，但各校证明形式、未毕业时的适用规则及最终材料须满足要求，不自动认定全部已豁免。 |
| 资金 | 美国按能够接受自费申请评估；欧洲只估录取，不含奖学金；加拿大研究型硕士按其正常招生和资助安排评估。 |
| 联系状态 | 不假定已获得潜在硕士导师的招生承诺、研究名额或资金承诺。 |

**“达标后”“等效通过后”“课程核对通过后”均为条件概率情景。** 如果明确门槛未满足且没有获准例外，机会应按接近0处理，不能直接使用条件区间。Alberta和Melbourne的条件情景还存在核心招生依据未核清的缺口。

本报告不把39个学校记录当作39次独立试验，也不以各校概率相乘来计算总体成功率。

UBC Physics MSc官方列出的2025年数据为193份申请、54份offer，整体约28%。这包含不同成绩、方向和身份的申请人，不能当作个人概率。本报告对申请人的估计低于整体比例，主要因为目前没有证明高年级成绩达到项目期望。

两封科研推荐已经确定，但多校要求三封。第三封优先考虑能具体评价核心物理学习能力的任课教师。Brown的系页与中央项目页推荐数量有表述差异，最终须以申请系统和项目确认的清单为准。

## 9. 申请投入建议

1. **优先把资格变成可确认事实。** KIT、Heidelberg、UZH、Geneva、Bern做课程与成绩等效核对；Western、UVic计算对应成绩区间。这些工作最可能改变目前的概率判断。
2. **认真完成美国独立硕士申请。** Stony Brook、Tufts、NYU、Northwestern、Texas A&M。对要求三封的项目，第三封优先来自能具体评价核心物理学习能力的任课教师。
3. **保留少量高质量冲刺。** McGill、LMU、IP Paris、PSL、EPFL、ETH。避免让低概率项目占去大部分准备时间。
4. **先解决缺口再投入完整申请。** SFU的GPA例外、Calgary的分段GPA和Physics GRE、Alberta与Melbourne的当前资格。Columbia和WashU还需考虑其课程或非thesis结构是否符合目标。

两项科研已经使申请具备具体、可审查的内容。现在最可能提高录取机会的是证明核心物理成绩、满足各校实际资格口径，并让推荐信具体说明独立工作能力。若高年级成绩明显好于CGPA 3.0，加拿大和部分欧洲项目可以上调评估；若核心课程仍接近3.0，应采用区间下端。任何上调都应基于新证据，不自动添加固定百分点。
