## 论文阅读与咨询内容

首读论文讨论 LMC 对本地暗物质速度分布、方向性反冲图及拒绝各向同性所需事件数的影响。信中联系 MaNGA 的模型假设敏感性，提出**待讨论、尚未实施**的起步任务：在简化反冲率模型中比较速度分布假设的影响。不是导师公布的招生课题，也不把 c–M 关系直接等同于本地速度分布。
