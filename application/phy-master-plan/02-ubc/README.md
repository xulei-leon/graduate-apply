## 选择与定制依据

Van Waerbeke 为 UBC Professor，官方导师资料列明 Astronomy MSc 和 Physics MSc 指导资格。本包采用 Astronomy MSc。研究方向包括弱引力透镜、暗物质分布、星系及结构形成；2026 年共同署名的 UNIONS 卫星子晕质量论文提供了具体联系点。当前课题经费、本人在该论文中的具体职责及 Fall 2027 名额均未确认。

研究匹配：**High（暗物质晕与统计推断）**；规划难度：**Reach**。MaNGA 旋转曲线中的质量—浓度简并、先验敏感性及后验诊断，可以连接到透镜模型中的子晕质量、宿主晕贡献与中心偏移。观测量和物理环境不同：现有经历不等于已经会做弱透镜、UNIONS 数据处理或星系团子晕分析，也未查明导师正在招收 MaNGA c–M 课题学生。

邮件以论文的质量分量分解和中心偏移处理切入，提出一个供讨论的模拟检验：生成包含宿主晕偏心的模拟透镜轮廓，比较正确纳入与忽略偏心时的子晕质量恢复。这是申请人希望学习的起步任务，不是已经开展的工作或导师公布的职位。
