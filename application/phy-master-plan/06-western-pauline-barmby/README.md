## 选择与定制依据

**研究匹配：High（方法与星系研究）；规划难度：Match（附条件）。** Barmby 官方 faculty 页明确研究 nearby galaxies、stellar populations 与 astroinformatics，尤其关注统计和机器学习在天体物理中的应用。2026 修订的合著论文比较不同测光特征／降维输入的 MLP 与 random forest 分类效果，与你的 Higgs 特征比较经验有具体方法重合；MaNGA 提供星系物理和统计分析背景。

这一匹配不是“导师以暗物质晕 c–M 为主要方向”。拟议联系点是科学数据中输入信息、分类污染与可靠性；你尚无经核实的球状星团观测、LSST catalogue processing、PCA / auto-encoder 研究经验。信中不把这些方法写成你已经熟练掌握的技能。

官网鼓励申请前联系导师，但未核到 Barmby 的 Fall 2027 MSc 名额声明。Match 只作学校申请规划判断，前提是满足三四年级课程平均要求并落实导师和资金，不能解释为录取保证。

## 论文阅读与咨询内容

首读论文以 LSST-like colors 比较球状星团候选分类输入，强调信息与污染限制。信中联系 Higgs 的输入比较与可靠性检查，提出**尚未实施、待讨论**的模拟测光噪声／输入选择敏感性分析。论文不是直接用 pyhf 做质量推断；分类污染与信号强度区间宽度不能当作同一指标。

Barmby 的合著关系已核查，具体子分析的个人分工没有独立确认，邮件使用 co-authored paper。申请人后续阅读；详见 [paper_reading_notes.md](paper_reading_notes.md)。
