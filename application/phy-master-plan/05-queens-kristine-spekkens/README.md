## 论文阅读与咨询内容

首读 *Bayesian Galaxy Asymmetry*，论文处理噪声对 HI 星系不对称性的影响，推导后验并考虑相关噪声，再应用于 WALLABY。邮件联系“个体测量的不确定性如何支持群体研究”，提出**尚未实施、待讨论**的简化模拟噪声／后验可靠性检验。这个想法不是导师已公布的招生项目。

论文处理的是噪声不确定性；原文明确未将中心不确定性与空间分辨率对真实不对称性的影响全面纳入。个人邮件不称该方法消除了全部系统误差，也不把论文里的 coverage test 写成自己已复现。详见 [paper_reading_notes.md](paper_reading_notes.md)。
