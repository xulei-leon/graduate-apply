## 对申请人的判断

这七项中，它的转专业入口最明确。两项科研足以提供 perseverance 和 transition into tech 的真实材料：可用诊断失效、先验敏感性或 AUC 与推断质量不一致的实例，说明为什么需要更系统的计算训练。

主要代价是 2.5–3 年及 bridge 的时间/费用。它适合有意进入 CS / software / ML 工程工作的选择；若主要目的仍是尽快进入 Physics PhD，须比较重复基础训练的机会成本。已有 Python / ML 实践不等于能免除整个 bridge。

GPA 正好踩线、Boston 需求及课程准备使它不能担当保底。Co-op 是机会和训练结构，不能作为录取后必然获得的工作或收入。
