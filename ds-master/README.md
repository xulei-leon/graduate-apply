# Data Science Master Applications

## Scope

Use this folder for data science or data analytics master programs that plausibly accept physics or other quantitative-STEM backgrounds.

## Target regions

- Canada
- USA
- UK
- Switzerland
- Singapore
- Hong Kong
- Australia

## File rules

- Create one markdown file per program using the existing naming convention in this folder.
- Note whether the program is open to non-CS backgrounds or explicitly requires CS/statistics prerequisites.
- Keep the official source URL visible in both the per-program file and the index table.
