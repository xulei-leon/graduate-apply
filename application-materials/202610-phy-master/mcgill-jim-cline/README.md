## 选择与定制依据

Jim Cline 属原名单两位首选之一，其主页确认研究集中于 particle physics/cosmology interface，包含暗物质模型、直接探测和银河系中的潜在暗物质湮灭信号。主页欢迎优秀 MSc / PhD 学生，但明确取决于经费，且必须通过学校项目申请。这支持发出咨询，**不代表 Fall 2027 已有名额**。

研究匹配：**Medium**。MaNGA 的参数简并、先验检查和数值推断可作为起点，但申请人尚无经核实的场论、暗物质模型构建或遗迹丰度计算经验。信中结合暗光子振荡论文，拟议“比较固定与允许变化的标准振荡参数对约束的影响”，这是待导师讨论的起步任务，不是导师公布的课题或申请人已完成的工作。规划难度：**Reach**，不据累计 GPA 达最低线推断录取机会。

本轮不选其余两人的原因：Katelin Schutz 的 contact 页当前明确无学生研究岗位；Adrian Liu 的主页明确因组内已满及 2027–2028 学年 sabbatical，目前不招收研究生或博士后。两条均为 2026-09-28 的页面状态，不推断永久停招，也不标成导师回信拒绝。
