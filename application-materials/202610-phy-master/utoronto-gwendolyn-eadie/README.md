## 选择与定制依据

官方 faculty profile 将 Eadie 列为 Associate Professor, DADDAA & Statistics，明确写有 astrostatistics、Bayesian hierarchical modelling、Milky Way structure and dynamics、MCMC，以及用层级贝叶斯方法研究银河系和其他星系的暗物质晕。

研究匹配：**High**。MaNGA 单星系联合后验向浓度—质量群体参数的传播，支持讨论层级推断与不确定性。信中结合球状星团论文的测量误差与距离—质量简并开头；不同数据和示踪体仍需学习，不写成已有银河系示踪体建模、球状星团分析或 Eadie 代码使用经验。拟议的模拟星团距离处理比较是讨论方向，不是已商定的研究任务。规划难度：**Reach**，尤其受 MSc 路径及学术要求限制。

## 阅读与下一步

已推荐 *Hierarchical Bayesian Inference of Globular Cluster Properties*（https://arxiv.org/abs/2311.03704），并核查 §3、§4.2、§5 及相关图注。两版邮件已用联合处理测量误差和未知星团中心、Fig. 8 的距离—质量简并建立联系，结尾收窄为模拟星团的距离处理比较；申请人计划随后阅读。详见[阅读说明](paper_reading_notes.md)。这不是暗物质晕测量论文，不将两种动力学问题等同。
