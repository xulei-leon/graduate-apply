## 选择与定制依据

官方 G+PS profile 将 Lister 列为 Professor，研究方向包括 ATLAS、Search for physics beyond the standard model、top quarks、dark matter、Machine Learning 和 Long-lived particles，并将 Physics MSc 列为可指导的相关论文项目。

研究匹配：**High（计算与统计方法）**。申请人的 Higgs open-MC、MLP 输入比较、pyhf、bootstrap 和覆盖率诊断提供直接方法依据；具体物理分析任务尚未匹配到已确认课题。信中结合 ATLAS 异常检测论文的分类器选择、pyhf 拟合和背景偏差验证，而不写成已做 jet tagging、长寿命粒子搜索、探测器开发或真实 ATLAS 数据分析。拟议“检查分类器选择与背景建模偏差对拟合结果的影响”是供讨论的范围有限任务，不是导师提供的职位。规划难度：**Reach**，资格须按 UBC 的成绩口径评估。

选择 Lister 而非 Hearty，是因为现有 Higgs 研究与 ATLAS 模拟及机器学习评估的方法联系更直接；不将 ATLAS 合作论文署名当作 Lister 本人负责某项子分析的证据。
