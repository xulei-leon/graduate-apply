## 邮件顺序

保持“论文兴趣—相关科研经历与成果—希望跟随导师继续学习和研究”的逻辑，正文按以下五个段落组织：

1. **身份与申请目的**：U of T Physics Specialist 本科生、预计 2027 年 6 月毕业、申请 Fall 2027 的具体项目。
2. **对导师论文的兴趣**：指出导师参与撰写的论文中引起兴趣的具体问题或方法，并通过共同的推断或检验步骤连接本人经历；默认不声明已完成阅读。
3. **科研经历与成果**：以 MaNGA 的研究问题、完成的分析和个人收获为主，列出手稿链接；段末补充 Higgs 的模拟数据、方法工作与可靠性检验。
4. **希望继续学习和研究**：表达希望在导师指导下继续研究，提出一个可讨论的起步方向，并说明需要学习的领域知识或方法。
5. **招生询问与下一步**：询问 Fall 2027 招生及背景适配，说明 CV 附件；若导师认为可能合适，请其回信告知方便的交流时间和方式。

## 按导师定制

- **项目与主题**：将学校、项目及学位替换为官方名称。主题中的 `Astronomy/Physics MSc` 是待选项，发送时只保留实际项目对应的名称；其他学位另行调整。英文主题可采用 `Fall 2027 Astronomy MSc inquiry: 【research focus】` 或 `Fall 2027 Physics MSc inquiry: 【research focus】`，只留一个具体研究关键词。
- **论文兴趣**：选择一篇相关的近期论文，将英文题名或简短描述设为链接。说明实际感兴趣的处理及其与 MaNGA 经历的联系，避免复述摘要或仅凭共同涉及暗物质、机器学习就认定匹配。核实导师的作者身份；合著关系不等于其负责某项子分析。
- **阅读表述**：“拜读了”以本人实际阅读为前提。可以先根据核实的资料准备草稿；尚未阅读时，改为“您参与撰写的论文……中，……引起了我的兴趣”。发送前应能解释兴趣点及研究联系。
- **后续研究**：围绕上述论文提出一个范围有限的模拟、拟合、数值比较或模型检验任务，作为供讨论的兴趣。说明希望学习什么，不预设导师正在招收该课题的学生。英文版区分希望加强的知识与方法技能，两类占位符按实际需要保留一项或两项，避免将学习方法写成开发新方法。非天体物理方向从可迁移的计算与统计方法建立联系，并说明需要补足的物理基础。
- **交流请求**：先询问招生和背景适配，再有条件地邀请简短交流，请对方回复时间及偏好的形式。可采用线上视频或其他双方合适的方式，不指定平台、时长或默认对方已同意。若导师公开说明招生受经费限制，可据实加入条件。

**MaNGA 是主要研究证据。** 保留独立完成研究分析、PyMC/MCMC、先验校正的重要性采样、模型假设与重加权稳定性检验，以及个人收获。620 指筛选后的盘星系分析样本，不代表测量精度或研究影响力。当前邮件写“第一作者手稿已完成”；若进一步列出投稿或发表状态，按最新事实核对，不由公开 PDF 推断已投稿或已发表。

**Higgs 是补充经历。** 简述 ATLAS 公开的 H → ZZ* → 2e2μ 模拟样本、MLP 特征组合比较、pyhf 似然分析，以及 bootstrap 和覆盖率诊断。保留项目仍在进行的状态；现有结果仍属探索性，不声称已建立显著或经校准的精度提升。按当前写法描述项目内容与本人工作，不列既往指导者姓名或机构；不将校外非官方指导经历写成大学官方项目、任职或合作组成员经历。

MaNGA 经历不直接证明已有弱透镜、星流、宇宙学模拟或粒子暗物质探测经验；Higgs 模拟分析不等于真实碰撞数据测量或探测器操作。新方向的准备需求在后续学习段中据实表达。

- 实际附上 CV 后使用“随信附上 CV”；未附时改为“如有需要，我可以提供 CV”，按实际情况选择。附件可命名为 `Hongyi_Xu_CV_2026.pdf`。成绩单仅按要求单独提供，不发送 Word 作为定稿附件；被要求报告 GPA 时按最新成绩单填写。

- 发送时使用邮件模板中的主题、称呼、正文与署名；本 README 仅作内部参考。
